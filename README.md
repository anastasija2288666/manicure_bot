# Telegram-бот записи на маникюр (aiogram 3)

Профессиональный бот для записи клиентов в студию маникюра с хранением данных в SQLite.

## Возможности
- **Главное меню** с кнопками: Прайс-лист, Записаться, Портфолио и адрес, Мои записи.
- **Пошаговая запись**: услуга → дата (ближайшие 5 дней) → свободное время → имя → телефон → подтверждение.
- **Занятые времена автоматически скрываются** для других клиентов (база `database.db`, записи не пропадают).
- **Уведомление мастеру** о новой записи (ID из `ADMIN_ID`).
- **Отмена записи** клиентом через раздел «Мои записи».

## Состав файлов
- `main.py` — точка входа бота.
- `config.py` — `BOT_TOKEN` и `ADMIN_ID` из переменных окружения (`os.getenv`).
- `database.py` — SQLite-база `database.db`, услуги, записи, логика свободных слотов.
- `keyboards.py` — клавиатуры меню и инлайн-кнопок.
- `handlers.py` — все хендлеры и машина состояний записи (FSM).
- `requirements.txt` — зависимости (`aiogram`).
- `.env.example` — образец файла переменных окружения.

## Деплой
1. Скопируйте файлы на сервер/компьютер с Python 3.8+.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` на основе `.env.example` и укажите в нём:
   - `BOT_TOKEN` — токен бота от @BotFather.
   - `ADMIN_ID` — ваш Telegram ID (узнать можно у @userinfobot).
4. Запустите:
   ```bash
   python main.py
   ```
   (Бот не запускался в рамках этой задачи — файлы подготовлены для деплоя.)

## Логика времени
Рабочий день: 10:00–20:00, слот — 30 минут. При выборе услуги проверяются активные записи на выбранную дату, и занятые/пересекающиеся интервалы скрываются из списка свободного времени.
